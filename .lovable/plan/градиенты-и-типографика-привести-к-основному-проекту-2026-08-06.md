# Градиенты и типографика: привести к основному проекту

## Что проверено

Сравнил наш код с `prod_robinzone_ai` (поиск по `gradient`, `bg-clip-text`, заголовкам).

### Градиенты

| Приём | Основной проект | У нас |
| --- | --- | --- |
| Градиент в заголовке | только вертикальный `from-white to-white/40` (и один раз `from-volt to-volt/60`) | такого приёма нет |
| `.text-gradient` | volt → plasma (`#9F6EFF`), используется лишь на Explore/404 | volt → sky |
| Полоски прогресса и шкалы | сплошной акцент; градиент только как shimmer (`transparent → volt → transparent`) | `linear-gradient(90deg, sky → volt)` в HeroPreviewCard (3 места), ResultsScreen, BrainSignals, HowItWorks, EngagementScore, History, ScoreGauge |
| Радиальные свечения | есть | есть — совпадает, не трогаю |

То есть диагональный sky→volt, который у нас размазан по шкалам и бейджам, в основном продукте в контенте не используется: там шкалы сплошные, а градиент — вертикальное затухание текста.

### Типографика заголовков

| Параметр | Основной проект | У нас |
| --- | --- | --- |
| Класс | `font-display font-extrabold uppercase` | смесь `font-bold` / `font-extrabold`, uppercase только в FinalCTA |
| Размер | `text-[clamp(2rem,6vw,3.75rem)]` / `clamp(1.5rem,5.5vw,2.75rem)` | фиксированные брейкпоинты `text-[32px] sm:text-[44px] lg:text-[60px]` |
| Трекинг / интерлиньяж | `-0.02em` / `leading-[0.9]`–`[0.95]` | `-0.025em` / `leading-[1.05]` |
| Баланс строк | `[text-wrap:balance]` | нет |
| Eyebrow | `text-[10px] font-extrabold uppercase tracking-[0.25em]` | `tracking-[0.1em]`–`[0.16em]`, вес 700 |

## Что сделаю

1. **Шкалы и полоски** — заменить `linear-gradient(90deg, sky → volt)` на сплошной `var(--volt)` в `HeroPreviewCard` (3 полоски), `ResultsScreen` (полоска и бейдж), `BrainSignals`, `HowItWorks`, `EngagementScore`, `_gated.history`. В `ScoreGauge` дуга — сплошной volt.
2. **Акцент в заголовках** — там, где нужен, использовать приём оригинала: `text-transparent bg-clip-text bg-gradient-to-b from-white to-white/40` (или `from-volt to-volt/60`).
3. **Утилиты в `src/styles.css`** — `.text-gradient` привести к оригиналу (volt → plasma), добавить `--gradient-hero`; брендовый volt→sky оставить только для логотипа/бренда.
4. **Заголовки секций** — формула оригинала: `font-display font-extrabold uppercase tracking-[-0.02em] leading-[0.9|0.95] text-[clamp(...)] [text-wrap:balance]` в `EngagementScore`, `HowItWorks`, `FinalCTA`, заголовках `UploadScreen` и `ResultsScreen`.
5. **Eyebrow и мелкие подписи** — `text-[10px] font-extrabold uppercase tracking-[0.25em]` (классы `.badge-*` не трогаю).
6. Обновить разделы «Типографика» и «Поверхности» в `DESIGN_SYSTEM.md` под фактические правила оригинала.

`SiteHeader`, `SiteFooter`, `MobileBottomNav` и админку не трогаю.
